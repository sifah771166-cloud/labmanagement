# Icon Placeholder

Untuk PWA yang lengkap, tambahkan icon dengan ukuran:
- 192x192 pixels → icon-192.png
- 512x512 pixels → icon-512.png

Letakkan di folder: `/public/assets/images/`

## Cara Membuat Icon

1. Buat logo/icon aplikasi Anda
2. Export dalam format PNG
3. Resize ke ukuran yang diperlukan
4. Simpan dengan nama:
   - `icon-192.png`
   - `icon-512.png`

## Tools Online untuk Membuat Icon
- https://realfavicongenerator.net/
- https://www.favicon-generator.org/
- https://favicon.io/

## Sementara Waktu
Aplikasi tetap bisa berjalan tanpa icon, hanya PWA install prompt yang tidak akan muncul.
