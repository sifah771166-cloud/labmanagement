## 💡 Tips

### Untuk User Baru
1. Mulai dengan [QUICK_START.md](QUICK_START.md)
2. Login dengan akun default (admin/admin123 atau user/user123)
3. Explore fitur-fitur yang tersedia
4. Baca [README.md](../README.md) untuk detail lengkap

### Untuk Administrator
1. Ganti password default sebelum production
2. Setup backup otomatis (lihat `scripts/backup.sh`)
3. Monitor logs secara berkala
4. Update dependencies secara rutin: `npm audit fix`

### Untuk Developer
1. Fork repository
2. Setup development environment
3. Baca [CONTRIBUTING.md](../CONTRIBUTING.md)
4. Buat branch untuk fitur baru
5. Submit Pull Request
